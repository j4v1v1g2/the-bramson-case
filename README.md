# THE BRAMSON CASE #

### ENGLISH

**Enter a world of mystery, ancient horrors and cosmic secrets.**

The Bramson Case is a horror adventure inspired by the stories of H. P. Lovecraft and the Cthulhu Mythos.

Explore a mysterious world, uncover hidden secrets and face an unsettling atmosphere where the unknown is never far away.

**Available platforms and features:**
- PC version.
- Android mobile version.
- Virtual joystick controls.
- Google Cardboard VR compatibility.
- Bluetooth controller support.
- Magic Window mode.
- Audio available in English and Spanish.

Free prologe coming soon. Full game planned for January 2027.
